# [Abstracted Tech](https://abstracted.tech/)

Personal site for Christopher Forte. Plain static HTML and one stylesheet (`src/css/site.css`), no build step.
Pushes to `master` deploy `src/` to GitHub Pages via `.github/workflows/static.yml`.

- `src/index.html`: home, C2Society, contact
- `src/projects/`: active projects and overviews of archived ones
- `src/community/`: talks and community work
- `src/puzzle/`: the puzzle door
