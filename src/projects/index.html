Projects

What I'm working on now, and an overview of the projects that have wound down, so the work behind them stays findable after the sites go dark.

Active

  • C2Society

    Nonprofit, since 2020

    A Las Vegas nonprofit dedicated to security awareness, formerly DC702. C2Society runs the weekly DC702 meetups, The Petting Zoo CTF, and the group's DEF CON contests, and includes the local TOOOL chapter for lockpicking and physical security awareness.

  • The Petting Zoo

    CTF workshop, with C2Society

    A workshop-style capture the flag event that introduces people to CTFs. It has been run for three-letter agencies, military groups, and local law enforcement, and at DEF CON 30 and 31. Challenges cover web attacks, binary exploitation, forensics, cryptography, and lockpicking, and the format can be tailored to whatever a group needs to learn.

Archived

  • Abstracted Solutions

    Security consultancy, around 2021 to 2024

    A small security and IT practice for small and mid-sized businesses, plus awareness work for residential clients. The idea was in the name: complexity is at odds with security, so abstract away what you can and make what's left easier to secure and maintain. Services ranged from penetration tests and physical assessments done with an adversarial mindset to help building security into development processes.

    It also ran trainings and events, including The Petting Zoo with DC702, and published plain language articles: Log4Shell: The Basics, Security Through Abstraction, and Protect Yourself, a starter guide to personal security hygiene.

    Closed. The site is offline; its content is archived in this site's repository.

  • The Unknown Space

    Puzzle-based learning

    "The best way to explain it is to do it." The Unknown Space built custom puzzles and challenges to teach technology, security concepts, and even onboarding material. The premise was that memorizing for a test isn't learning; applying information to solve a problem is.

    Retired. The domain now points to C2Society, which carries the idea forward.

  • Art of Codes

    Puzzle site, passion project

    A collection of puzzles meant as a path to learning. Each challenge showed off a subject I found interesting or paid tribute to a puzzle that inspired me. Over time it also became a playground for trying web attacks and new web technologies.

    Retired. The domain now points to C2Society.

  • Threshodl

    Crypto wallet, ThreeBx, 2018

    Threshodl moved cryptocurrency off-chain using "micro-wallets," so value could change hands without a blockchain transaction for every transfer. As CTO of ThreeBx I designed the concept, wrote the first beta of the mobile app and its backend services, and filed the patent application (US 15/978,008, Systems and methods for facilitating off-the-blockchain cryptocurrency transactions) in May 2018.

    Ended when ThreeBx dissolved; the patent was not pursued. Source remains on GitLab.

  • Shark Trap

    Technical advisor

    Shark Trap builds "super shufflers" that bring intelligence and optimization to casino table games. I advised on algorithms for marked card detection, hashing and randomization, and computer vision.

    Past advisory role.
